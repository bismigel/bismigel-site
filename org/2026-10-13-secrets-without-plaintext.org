Secrets were the thing I understood worst when I started, and the thing that most
often showed me I didn't understand the rest. The rule I ended up with is simple:
no secret sits in git as readable text. Getting there took a couple of wrong turns.

* On the host: SOPS with age

Host secrets — the tunnel credentials, the cluster token — stay encrypted in the
NixOS repo. They're decrypted at activation, using the machine's own SSH host key as
the age identity. There's no service to run and nothing to re-do when I rebuild a
box, so I've never wanted to change this one.

#+begin_src shell
sops secrets/homelab.yaml    # edit; re-encrypts on save
#+end_src

* In the cluster: I started with Sealed Secrets

My first cluster setup was Sealed Secrets. A controller in the cluster holds a
private key, the matching public key encrypts a secret, and the encrypted file is
safe to commit:

#+begin_src shell
kubectl create secret generic app \
  --from-literal=KEY=value --dry-run=client -o yaml \
  | kubeseal --format yaml > sealed-secret.yaml
#+end_src

It felt self-contained. I didn't see the catch until the cluster grew: *every
cluster has its own sealing key*, so a sealed secret only opens on the one cluster
it was sealed for. Lose that cluster and its key, and the secret is gone for good. I
picked it by copying what other people did, without thinking about there being more
than one cluster.

* What I use now: Bitwarden, injected by External Secrets

I moved the cluster half to a managed store — *Bitwarden Secrets Manager* — with
*External Secrets Operator* in front. The values live *outside* the lab, so wiping a
cluster doesn't lose them, and to rotate a password I edit it in Bitwarden instead of
re-sealing a file. The host half stayed on SOPS.

I'd like to say I reasoned my way here. Really, the sealing-key problem forced me to
move, and the managed store is what made the problem go away. Sealed Secrets is gone
now.

* The rule, and the mistake

Plaintext never enters git. If a value has to live in the repo, it's encrypted first.
And back up the keys to whatever store you pick — without them, none of it opens
again. I learned that the slow way, which is the only way I seem to learn.
