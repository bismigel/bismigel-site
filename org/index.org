I run a homelab the way I would run production: declarative hosts, one GitOps control
plane, a three-node etcd quorum, and a small Cloudflare edge. These posts are the build
log and the incident write-ups, from a traditional sysadmin learning Kubernetes.

** What this is

The same stack, chosen for a lab and not a demo: NixOS hosts rebuilt from one command,
k3s with embedded etcd, ArgoCD as the only way in, Longhorn for volumes that must move,
and Prometheus with rules I actually act on. Every post ends in a thing that broke and
what it cost, because that is where the learning lives.

** What this is not

Not a tutorial, not a product, and not finished. The hardware is second-hand, the
planned gaps are listed out loud (no penetration test, no image signing, no disaster
recovery rehearsal yet), and the repos are private — so the prose is the artifact. The
long version of the architecture lives in the
[[https://bismigel.dev/projects/bakuran-homelab/][technical reference]].
