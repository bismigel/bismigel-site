#+TITLE: The homelab, in two machines
#+DATE: 2026-09-24
#+FILETAGS: homelab:nixos:kubernetes

Everything runs on two boxes. One hosts websites, the other is a media server.

* Two roles

- =sitaw= (AMD Ryzen): hosting. Sites, ArgoCD, ingress, the tunnel.
- =calamansi= (Intel i5): media. Sonarr, Radarr, Prowlarr, Bazarr, qBittorrent,
  Jellyfin.

Keeping them apart means a busy transcode never takes a website down.

* Everything is NixOS

Both machines are described in one flake. The OS is code:

#+begin_src nix
services.k3s = {
  enable = true;
  role = "server";
  extraFlags = [ "--disable" "traefik" "--disable" "servicelb" ];
};
#+end_src

To rebuild a machine I run:

#+begin_src shell
nix run github:serokell/deploy-rs -- .#sitaw
#+end_src

* Kubernetes, but small

Each box runs a single node k3s. I disable the bundled Traefik and service load
balancer, and use ingress-nginx instead, so ingress is explicit.

* GitOps

ArgoCD keeps the cluster in sync with Git. A push is the deploy:

1. a code change lands in a repo
2. CI builds and pushes an image
3. CI bumps the image tag in the manifests
4. ArgoCD applies it

CI never holds cluster credentials. That is the point.

* The edge

One =cloudflared= tunnel connects out to Cloudflare. Public hostnames route to
=ingress-nginx= on the hosting box. Nothing is port-forwarded.
